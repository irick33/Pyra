# Changelog

## 0.3.0rc1 — Architecture & Workspace

2026-11-09. Переход к v0.3 по запросу пользователя, на базе 0.2.1rc1.
Кандидат релиза: длительная нативная приёмка Windows ещё необходима.

### Обновление боковой панели

- Вместо неоднозначных символов — единые векторные иконки с постоянными подписями.
  Панель занимает 88 логических пикселей; разделы сгруппированы, «Справка» находится снизу.
- Добавлены состояния наведения, клавиатурного фокуса и выбранного раздела,
  пояснения с действующими сочетаниями клавиш и названия для средств доступности.
- «Запуск» открывает вывод программы, «Отладка» — панель отладчика; добавлен прямой доступ к Git.
  Выделение следует за переключением нижних вкладок и отделением/возвратом панелей.
- «Проект» открывает дерево и переводит в него фокус; «Справка» открывает руководство.
  Безымянный «+» над деревом заменён кнопкой «Новый файл».
- Новых зависимостей и постоянно работающих таймеров навигации нет.
  Повторная проверка: `docs/VALIDATION_SIDEBAR_UI_RU.md`.

### Добавлено

- Контроллеры документов, сессии, компоновки, Ruff и фоновых задач; сборка GUI вынесена
  из MainWindow. Новых зависимостей нет, AI и плагины не добавлены.
- Атомарная сессия с несохранёнными буферами, предыдущей копией и переносом старых recovery.
  Один поток записи объединяет очередь; снимки текста кешируются по ревизии.
  Закрытие IDE сохраняет черновики; при ошибке записи окно остаётся открытым.
- Сохранение порядка вкладок, активного документа, курсора, прокрутки, breakpoints,
  закрепления и компоновки. Отложенные черновики переживают `--no-restore` и открытие другого проекта.
- Закрепление и массовое закрытие незакреплённых вкладок; режим фокуса; клавиатурная навигация.
- Независимое отделение и пристыковка инструментальных панелей, регулируемая структура файла,
  восстановление и сброс компоновки. «Журнал» в нижней панели переименован в «Вывод».
- Диалог фоновых задач, отмена поиска, освобождение завершённых потоков,
  отказ от устаревших результатов. Regex-поиск ограничивает сложность через Qt/PCRE2.
- Тесты жизненного цикла и воспроизводимый `tools/soak_workspace.py`; расширен self-test упаковок.

### Исправлено

- Общий QSS больше не подменяет шрифт консоли после расчёта сетки. Выделение не меняет
  группировку отрисовки символов и не закрашивает хвосты пустых строк.
- Выделение удерживает видимый текст при поступлении вывода. Ctrl+C копирует выделение,
  без выделения прерывает программу; Esc возвращает живой экран. Исправлены широкие глифы.
- I001 явно обозначается как замечание к стилю с пояснением о пустых строках/порядке импортов.
  Ctrl+Alt+L выполняет безопасное исправление импортов и форматирование одним действием Undo.
- Отмена Job завершает дерево дочерних процессов. Перезапуск задачи не наследует состояние отмены.
- При обнаружении Python нормализуются `..` в пути без раскрытия symlink виртуального окружения.

Результаты и ограничения: `docs/VALIDATION_0.3_RU.md`.

## 0.2.1rc1 — Windows Stability & Packaging

Кандидат релиза от 2026-11-08. Полный критерий 0.2.1 ещё не закрыт: нужна
нативная приёмка Windows 10/11 для обеих упаковок. Это не выпуск 0.3.

### Добавлено

- Фоновое обнаружение Python с отменой: окружения проекта, сохранённые пути,
  PATH, Windows Launcher, реестр PEP 514 (обе разрядности), типичные папки всех
  локальных фиксированных дисков. Любой нестандартный путь выбирается вручную.
- Постоянный список проверенных интерпретаторов и выбор для каждого проекта.
  Проверяются CPython, версия, GIL, разрядность и принадлежность к venv.
- «Справка → Журнал ошибок»: ограниченные ротируемые логи, копирование и экспорт.
- Один сборщик для onefile/onedir/both, метаданные сборки, явное указание Python
  для первоначальной настройки независимо от диска и регистрации в системе.
- Автоматический `--self-test` для исходников и готового EXE, отдельный замер
  первого показа окна, инструменты измерения задержек и полного дерева процессов.

### Исправлено

- При старте GUI больше нет синхронного запуска нескольких Python с таймаутами.
- Pyra.exe, pythonw.exe, py.exe и Windows Store aliases не выбираются как Python.
- Неверный или зависший Python не заменяет рабочий выбор; проверка ограничена 5 секундами.
- Сохраняется путь к Python внутри venv, в том числе если это символьная ссылка.
- Jedi/debugpy в сборке запускаются реальным выбранным Python с исходниками
  служб из пакета. Устранена зависимость от stdio `--windowed` и запуска
  Pyra.exe в качестве Python. В проект не требуется устанавливать эти пакеты.
- Из внешнего окружения исключены наследуемые PYTHONHOME/PYTHONPATH и пути
  библиотек упаковщика. На Windows после загрузки Qt сбрасывается путь DLL.
- У сборщика нет жёстко заданных каталогов site-packages или диска C:.
- Очередь Jedi сбрасывается при смене проекта/окружения; старые ответы не применяются.
- Список пакетов старого окружения не подменяет новое после переключения.
- Поиск Python не очищает таблицу пакетов текущего окружения.
- Таймаут проверки Python/списка пакетов/Ruff не оставляет задачу навечно занятой.
- Ошибки запуска процессов и терминала доступны в журнале с действиями для исправления.

### UI и совместимость

Существующая тёмная тема и рабочие панели сохранены. В панели окружения появился
компактный список Python и кнопка поиска/отмены; добавлен диалог журнала без
постоянной новой панели. Старые настройки и резервные копии не удаляются.
Зависимости IDE остались прежними; новые инструменты сборки/тестов — отдельные.

Результаты тестов и замеров: `docs/VALIDATION_0.2.1_RU.md`.
