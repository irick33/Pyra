## О проекте

**Pyra** — специализированная IDE для Python с акцентом на скорость запуска, отзывчивый интерфейс и удобную повседневную разработку. В отличие от универсальных редакторов, Pyra сфокусирована на работе с Python-проектами.

Проект находится в активной разработке. Текущая версия исходного кода — **0.3.0 RC1** (release candidate); часть сценариев ещё требует проверки на Windows.

## Возможности

- **Редактор Python** на QScintilla: подсветка синтаксиса, работа со вкладками, точки останова.
- **Интеллектуальная работа с кодом** с помощью Jedi: подсказки и анализ Python-кода.
- **Проверка и форматирование** через Ruff, включая исправление порядка импортов.
- **Запуск программ** во встроенном терминале с поддержкой интерактивного ввода (`input()`) и ANSI-вывода.
- **Отладка** через `debugpy`: breakpoints и просмотр состояния выполнения.
- **Рабочее пространство**: дерево файлов, поиск, Git, инструменты окружения и управления пакетами.
- **Выбор интерпретатора** для проекта, включая виртуальные окружения.
- **Восстановление сессии**: вкладки, несохранённые черновики, положение курсора и компоновка панелей.
- **Настраиваемая компоновка** с отделяемыми панелями и режимом фокуса.
- **Фоновые задачи** для длительных операций, чтобы интерфейс оставался отзывчивым.

> Pyra стремится к высокой производительности, но конкретные показатели запуска, потребления памяти и скорости работы зависят от компьютера и сборки. Результаты тестирования см. в [`docs/`](docs/).

## Скачать готовую версию

1. Откройте [**Releases**](https://github.com/irick33/Pyra/releases).
2. Выберите актуальный релиз и скачайте сборку для Windows, если она опубликована.
3. Для сборки **onefile** запустите `Pyra.exe`. Для **onedir** распакуйте архив целиком и запускайте `Pyra.exe` из папки приложения.
4. При первом запуске выберите установленный Python для выполнения проектов.

**Важно:** Pyra включает собственные инструменты IDE, но запускает ваш код через **отдельно установленный интерпретатор Python**. Готовый `.exe` не заменяет установку Python для выполнения ваших скриптов.

## Запуск из исходного кода

Требуется обычный **CPython 3.10–3.15 с GIL** и доступ к интернету при первоначальной установке зависимостей.

```powershell
git clone https://github.com/irick33/Pyra.git
cd Pyra
.\start.bat
```

`start.bat` подготавливает виртуальное окружение `.ide-venv` и запускает IDE. Если Python находится по нестандартному пути:

```bat
set "PYRA_BOOTSTRAP_PYTHON=D:\Python315\python.exe"
start.bat
```

Замените путь примером расположения Python на своём компьютере.

## Сборка `.exe` на Windows

```bat
build_exe.bat onefile
```

Другие режимы:

```bat
build_exe.bat onedir
build_exe.bat both
```

Результаты сборки:

| Режим | Расположение |
| --- | --- |
| `onefile` | `dist\onefile\Pyra.exe` |
| `onedir` | `dist\onedir\Pyra\Pyra.exe` |

Для распространения `onedir` необходима **вся папка** со служебными файлами, а не один EXE. Подробности: [инструкция по сборке](BUILD_EXE_RU.md).

## Технологии

- **Python** — логика приложения.
- **PyQt6 + QScintilla** — графический интерфейс и редактор.
- **Jedi / parso** — анализ и автодополнение кода.
- **Ruff** — диагностика и форматирование.
- **debugpy** — отладка.
- **pyte + PTY/ConPTY** — терминал.
- **PyInstaller** — сборка Windows-приложения.

## Статус проекта и планы

**v0.3.0 RC1** развивает архитектуру, боковую навигацию и управление рабочим пространством. Перед стабильным выпуском необходима полноценная проверка готовых сборок на Windows 10/11.

Возможные будущие направления: дальнейшая оптимизация, улучшение интерфейса, расширение средств анализа и отладки. **AI-функции, система плагинов и автоматическое обновление в текущей версии не заявлены как готовые возможности.**

Изменения по версиям: [CHANGELOG.md](CHANGELOG.md).
