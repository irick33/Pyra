# Pyra 0.3.0 RC1

Полный исходный проект следующей версии по ROADMAP, на базе 0.2.1 RC1.

- Восстановление несохранённых вкладок и компоновки; закрепление вкладок; Focus Mode.
- Отделяемые и регулируемые панели; клавиатурная навигация; управление отменой задач.
- Исправлено смещение выделения консоли, фиксация копируемого текста при новом выводе.
- I001 показан как замечание к стилю, исправляется Ctrl+Alt+L одним действием Undo.
- GUI и прикладные контроллеры разделены; зависимости прежние; AI/плагины не добавлены.
- Обновлена боковая панель: подписи, единые векторные иконки, активный раздел,
  понятные подсказки, раздельные «Запуск»/«Отладка», Git и кнопка «Новый файл».

После обновления панели повторно прошли 78 тестов на Python 3.12 и 78 на 3.15.
Кнопки и переходы проверены реальными Qt-событиями; подробности и снимки —
`docs/VALIDATION_SIDEBAR_UI_RU.md`.

Предыдущие проверки ядра v0.3: 78 тестов на Python 3.12 и 78 на 3.15; исходники и обе Linux-сборки —
по 11 встроенных проверок. За 5 минут нагрузочной сессии: 26 документов, 2961 правка,
60 контрольных точек; восстановление точное, все службы завершились.
Замеры Linux/offscreen: запуск из исходников — медиана 233 мс, ввод p95 1,56 мс,
пустое окно около 70 МиБ RSS. Подробности и сырые результаты — `docs/VALIDATION_0.3_RU.md`.

Статус RC: Windows-сборка и многочасовая приёмка на Windows ещё не выполнены.
Один запуск Linux-бенчмарка завершился SIGSEGV; семь повторов прошли. Причина
не установлена, исправление этого сбоя не заявляется. Критерий готовности
стабильного релиза остаётся открытым.

Запуск: `start.bat`. Сборка в Windows: `build_exe.bat onefile` или `build_exe.bat onedir`.
Для Python вне PATH используйте `PYRA_BOOTSTRAP_PYTHON`, как описано в README_RU.md.
Архив не содержит готового Windows EXE.
