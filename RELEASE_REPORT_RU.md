# Pyra IDE 0.4.0 RC2 — отчёт о проверке

**Версия:** 0.4.0rc2 (исходники, не финальный релиз).
**Основа:** Pyra_IDE_v0.4.0_RC1.zip, содержащий незавершённую версию 0.4.

## Проверка функций ROADMAP

По исходникам присутствуют ключевые возможности **v0.4 Performance & Navigation**:
- `Ctrl+P`: индекс файлов и ограниченный фоновой поток, сортировка, выбор строки и столбца.
- `Ctrl+Shift+P`: палитра команд, `Ctrl+Shift+F`: поиск по проекту.
- История переходов, breadcrumbs, недавние проекты, переключение вкладок и панелей.
- Ленивая инициализация рабочих процессов, кэш структуры файла, дебаунс
  и ограничение фоновых очередей, облегчённый режим крупных исходников.
- Инструменты замера запуска, ввода, памяти и упаковок доступны в `tools/`.

**Важно:** наличие кода и существующих тестов не доказывает успешную работу GUI
или выполнение целевых показателей на Windows. Полный критерий готовности v0.4
не подтверждён, поскольку нет воспроизводимого сравнения v0.3 и v0.4
на одинаковой среде. Критерии Windows v0.2.1 и длительной работы v0.3
также остаются открытыми.

## Изменения RC2

- Исправлена версия приложения (из 0.3.0rc1 в 0.4.0rc2).
- Исправлена логика восстановления видимости панелей из сохранённого Focus Mode.
- Исправлено некорректное предположение о нижней панели в GUI-тесте и добавлен
  тест на восстановление намеренно скрытой панели.
- Без изменений функционального API выполнено выделение Qt-независимого
  алгоритма индексации в `pyra/file_index_core.py` для автономных проверок.
- Добавлены автономные тесты, три Qt-регрессионных теста навигации (запуск
  ожидает Windows/Qt) и синтетический бенчмарк поиска.
- Обновлены README, CHANGELOG и инструкции проверки.

## Результаты

- Архив RC1 распакован, проверка ZIP завершилась без ошибок.
- Проверка синтаксиса (`compileall`) исходников, инструментов и тестов — пройдена
  на Python 3.13.5.
- `python -m pytest -q --noconftest tests/test_file_index_core.py tests/test_core_runtime.py`
  — **14 passed**, Linux, Python 3.13.5.
- Сервис Jedi через штатный JSON-протокол: `goto`, `signature`, `references`,
  `complete` и `help` реально исполнены на многофайловом проекте.
- Проверка CLI сборщика `python tools/build.py --help` — пройдена; сам EXE не собран.
- Навигационный бенчмарк на 5 000 синтетических файлов: подробности в
  `docs/benchmark-navigation-0.4-rc2-linux.json`. Отсутствуют замеры GUI в RC2.
- Исторический тестовый отчёт RC1: **73 passed, 1 failed, 4 skipped**
  на Python 3.12. Этот набор не был повторно запущен в RC2 из-за недоступности Qt.

## Открытые ограничения и статус релиза

- Qt/PyQt6-QScintilla не установлены, скачать пакеты здесь не удалось.
  Полная проверка PyQt GUI, PTY/ConPTY, Ruff через GUI, отладки, восстановления
  layout и всей регрессии (включая два изменённых GUI-теста) не выполнялась.
- Windows 10/11, обе сборки PyInstaller, Python 3.15 не доступны для запуска
  в текущей среде; их совместимость не подтверждена этим отчётом.
- Холодный/повторный запуск GUI, дерево памяти Qt процессов, p95 ввода, сравнение
  onefile/onedir и soak-тест необходимо измерить на целевой Windows.
- Исторический SIGSEGV в Linux-бенчмарке v0.3 остаётся неразобранным.

**Решение:** v0.4.0 RC2 является обновлённым кандидатом для Windows-приёмки,
но **не** выпуском v0.4.0 stable. Инструкции и чек-лист: `docs/VALIDATION_0.4_RU.md`
и `BUILD_EXE_RU.md`.
